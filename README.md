# 🐚 CurveSynth 🐚

**CurveSynth** — это простой стерео-синтезатор на Python с базовыми возможностями wavetable-генерации звука и огибающей ADSR. Проект создан для обучения и демонстрации, как на чистом Python реализовать VST-подобный синтезатор без C++.

---

## 📋 Основные возможности

* **Wavetable-генерация**: поддержка базовых форм (Sine, Square, Saw, Triangle) и White Noise.
* **ADSR-огибающая**: контролируйте Attack, Decay, Sustain и Release в режиме реального времени.
* **Стерео-микс**: управление детюном (Detune), громкостью (Volume) и панорамой (Pan).
* **Интерактивный GUI**: выполнен на `tkinter`, небесная пастельная палитра, анимация формы волны.
* **Встроенная визуализация**: отображение текущей формы звуковой волны в реальном времени.
* **Полноценная клавиатура**: две октавы, включая диезы и бемоли, переключение октавы кнопками.
* **Случайная генерация**: одна кнопка — и новые параметры синтеза устанавливаются случайно.

## 🚀 Установка

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/ваш_логин/CurveSynth.git
   cd CurveSynth
   ```
2. Создайте виртуальное окружение и активируйте его:

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS/Linux
   source venv/bin/activate
   ```
3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   *Если `requirements.txt` отсутствует, установите вручную:*

   ```bash
   pip install numpy sounddevice
   ```

---

## ▶️ Запуск

```bash
python gui.py
```

Откроется окно **CurveSynth**. Используйте пробел или мышью по клавишам для извлечения звука.

## 🎛️ Управление

| Параметр       | Описание                       |
| -------------- | ------------------------------ |
| Waveform       | Выбор волновой таблицы         |
| Frequency (Hz) | Частота генерации              |
| A, D, S, R     | Параметры огибающей ADSR       |
| Detune (cents) | Детюн в центах                 |
| Volume         | Громкость                      |
| Pan            | Панорама (лево/право)          |
| Octave         | Переключение октавы            |
| C, C#, D … B   | Клавиши виртуальной клавиатуры |
| Randomize      | Случайная генерация параметров |
